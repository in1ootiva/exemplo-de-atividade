# ⚡ Quick Start - CRM Kanban

Guia rápido para começar em **5 minutos**!

## 🚀 Instalação Rápida

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Abrir no navegador
# http://localhost:5173
```

## ✅ Checklist Inicial

Ao abrir pela primeira vez:

- [ ] ✨ Você verá 6 colunas padrão já configuradas
- [ ] 📊 Estatísticas no topo (Negociações: 0, Valor Total: R$ 0,00)
- [ ] ➕ Botão "Adicionar Negociação" em cada coluna
- [ ] ⚙️ Menu de três pontos em cada coluna

## 🎯 Teste em 3 Passos

### 1️⃣ Adicione sua primeira negociação

- Clique em **"Adicionar Negociação"** na coluna "Novo Lead"
- Preencha:
  - **Nome:** "Website para Empresa ABC"
  - **Valor:** 5000
  - **Contato:** "João Silva"
  - **Email:** "joao@empresa.com"
- Clique em **"Adicionar Negociação"**

### 2️⃣ Mova o card

- Clique e **arraste** o card para "Contato Feito"
- Veja como é fluido! 🎨

### 3️⃣ Edite a negociação

- Clique no **card**
- Adicione uma **nota**: "Cliente pediu orçamento detalhado"
- Clique em **"Salvar Alterações"**

## 🆘 Problemas?

### "npm install" dá erro

**Solução:**
```bash
# Limpe o cache
npm cache clean --force

# Delete node_modules e package-lock.json
rm -rf node_modules package-lock.json

# Instale novamente
npm install
```

### Página em branco

1. Abra o **Console do navegador** (F12)
2. Veja se há erros em vermelho
3. Verifique se rodou `npm install`

### Cards não salvam

- ❌ **NÃO use modo anônimo/privado**
- ✅ Use sempre o mesmo navegador
- ✅ Não limpe os dados do navegador

## 🎨 Personalização Rápida

**Adapte as colunas ao seu processo:**

1. Renomeie as colunas existentes
2. Ou exclua e crie novas do zero
3. Não há limite!

**Exemplos:**
- Designer: `Briefing → Rascunho → Revisão → Aprovado`
- Dev: `Análise → Desenvolvimento → QA → Deploy`
- Vendedor: `Lead → Qualificado → Demo → Proposta → Fechado`
