# CRM Kanban MVP

Um CRM visual e simples baseado em Kanban para freelancers e pequenas equipes gerenciarem seu pipeline de vendas.

## 🚀 Características

- ✅ Interface Kanban visual e intuitiva
- ✅ Drag-and-drop para mover negociações
- ✅ Persistência automática no navegador (localStorage)
- ✅ Sem necessidade de cadastro ou login
- ✅ 100% client-side (sem backend)
- ✅ Responsivo para desktop e mobile
- ✅ Interface moderna com shadcn/ui

## 🛠️ Stack de Tecnologia

- **React 18** com TypeScript
- **Tailwind CSS v3** para estilização
- **shadcn/ui** para componentes
- **@dnd-kit** para drag-and-drop
- **Vite** como bundler
- **localStorage** para persistência

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build
```

## 🎯 Funcionalidades

### F1: Quadro Kanban (Pipeline Visual)
- Visualização de colunas verticais
- Colunas padrão pré-configuradas
- Drag-and-drop fluido

### F2: Gestão de Negociações (Cards)
- Adicionar negociações com informações essenciais
- Editar cards existentes
- Excluir negociações
- Campos: Nome, Valor, Contato, Email, Telefone, Notas

### F3: Configuração de Colunas
- Renomear colunas
- Adicionar novas colunas
- Excluir colunas

### F4: Persistência Local
- Salvamento automático
- Recuperação de estado ao recarregar
